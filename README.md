# سامانه جامع و یکپارچه کیهان بیوتی (ARAYESHI Retail ERP)
## خرده‌فروشی تخصصی لوازم آرایشی و بهداشتی

این پلتفرم یک Retail ERP تمام‌عیار، رویدادمحور و با سازگاری تراکنشی کامل (ACID) است که تمامی عملیات فروشگاهی POS، انبارداری با متد FEFO، تدارکات و خرید، حسابداری استاندارد دوبل، باشگاه مشتریان ۳۶۰ و کیف پول را به صورت همگام متصل و یکپارچه کرده است.

---

## 🌟 قابلیت‌ها و تمایزات کلیدی

### ۱. حسابداری استاندارد دوبل (Double-Entry General Ledger)
- هر رویداد کسب‌وکار (فروش، بیعانه، خرید کالا، مرجوعی، تعویض، هزینه، تبدیل به تستر و انبارگردانی) دارای سند متناظر دوبل تراز است (`SUM(debit) == SUM(credit)`).
- کدینگ حساب‌ها شامل حساب‌های اختصاصی:
  - **۱۰۱ صندوق نقد** | **۱۰۲ بانک و کارتخوان** | **۱۰۳ موجودی کالا** | **۱۰۶ اسناد دریافتنی (چک)**
  - **۲۰۱ حساب‌های پرداختنی** | **۲۰۵ تعهد کیف پول مشتریان**
  - **۴۰۱ درآمد فروش** | **۴۰۳ تخفیفات نقدی** | **۴۰۴ برگشت از فروش**
  - **۵۰۱ بهای تمام شده کالای فروش رفته (COGS)**
  - **۶۰۳ هزینه وفاداری** | **۶۰۴ هزینه تستر** | **۶۰۷ ضایعات و افت کالا** | **۶۰۸ مغایرت انبارگردانی**

### ۲. انبارداری پیشرفته و تخصیص FEFO
- **تخصیص هوشمند بر اساس تاریخ انقضا (First Expired, First Out)** با محاسبه دقیق موجودی آزاد: `available = quantity - reserved_quantity`.
- **حفاظت کامل از کالاهای رزرو بیعانه (Layaway)** در برابر نشت به فروش‌های عادی.
- تفکیک کالای مرجوعی سالم (بازگشت به انبار) از کالای بازشده و معیوب (انتقال به ضایعات).

### ۳. صندوق و فروش یکپارچه (POS & Split Payments)
- پرداخت‌های ترکیبی تفکیک‌شده به حساب‌های معین مربوطه (نقد به ۱۰۱، کارت به ۱۰۲، کیف پول به ۲۰۵، امتیاز به ۶۰۳).
- محاسبه دقیق وضعیت پرداخت (`PAID`, `PARTIAL`, `UNPAID`) بر اساس مجموع مبالغ دریافتی.
- گارد ضد مرجوعی تکراری (Anti-Double-Return) و محاسبه سروری مبالغ استرداد.
- فرآیند اتمیک تعویض کالا (Exchange) با تسویه آنی مابه‌التفاوت.

### ۴. تدارکات و حسابداری تأمین‌کنندگان (Procurement & AP)
- ثبت رسید فاکتورهای خرید با ثبت بچ، تاریخ انقضا، و صدور اتوماتیک سند `Dr 103 / Cr 201`.
- تسویه بدهی تأمین‌کنندگان با نقد/بانک/چک (`Dr 201 / Cr 102`).
- برگشت از خرید به تأمین‌کننده و کسر موجودی (`Dr 201 / Cr 103`).
- کاردکس گردش حساب تأمین‌کننده و گزارش سنی‌بندی بدهی‌ها (Aging).

### ۵. باشگاه مشتریان ۳۶۰ و کیف پول
- کیف پول به عنوان بدهی تجاری با ضمانت عدم منفی‌شدن (`wallet_balance >= 0`).
- تراکنش‌های علامت‌دار معین کیف پول منطبق با مانده جاری.
- تبدیل امتیاز به کیف پول همراه با شناسایی هزینه وفاداری.

### ۶. موتور تطبیق و عدم مغایرت (Reconciliation Engine)
- پایش و مانیتورینگ مستمر ۸ گانه: تراز اسناد، عدم وجود موجودی منفی، عدم تجاوز رزرو از موجودی، عدم منفی‌بودن کیف پول، تطابق پرداخت‌های فاکتور، عدم انحراف کیف پول و امتیازات، و تراز کل دفتر کل.
- اندپوینت گزارش مدیریتی: `GET /api/admin/reconciliation`.

## 🛠 ابزارهای خط فرمان و توسعه

```bash
# اجرای سامانه
npm start

# اجرای آزمون‌های خودکار یکپارچگی (Tiers 1–4)
npm test

# اجرای مایگریشن‌های دیتابیس
npm run migrate

# پشتیبان‌گیری برخط از پایگاه داده
npm run backup

# بازیابی ایمن پایگاه داده از پشتیبان
npm run restore
```
