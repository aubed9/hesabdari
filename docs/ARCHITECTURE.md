# معماری فنی سامانه یکپارچه کیهان بیوتی (ARAYESHI Retail ERP)

## ۱. نمای کلی سیستم
سامانه یک Retail ERP چندلایه‌ای، رویدادمحور و با سازگاری همگام (Synchronous Strict Consistency) است که برای فروشگاه‌های خرده‌فروشی تخصصی لوازم آرایشی و بهداشتی طراحی شده است.

## ۲. اصول کلیدی طراحی
1. **تراکنش‌پذیری اتمیک (ACID)**: هر رویداد کسب‌وکار (خرید، فروش، مرجوعی، تبدیل به تستر، انبارگردانی، تسویه تأمین‌کننده) در یک تراکنش واحد انجام می‌شود.
2. **ثبت سند دوبل حسابداری (Double-Entry)**: هیچ موجودی یا حساب پولی بدون سند متناظر دوبل تغییر نمی‌کند (SUM(debit) == SUM(credit)).
3. **تخصیص انبار با متد FEFO**: کالاها بر اساس نزدیک‌ترین تاریخ انقضا خارج می‌شوند؛ کالاهای رزروشده در سفارش‌های بیعانه‌ای از موجودی آزاد تفکیک می‌شوند.
4. **تطبیق و راستی‌آزمایی مستمر (Reconciliation)**: موتور تطبیق در ۸ بعد کلیدی صحت داده‌ها را پایش می‌کند.
