# راهنمای آزمون‌های خودکار و تضمین کیفیت (Testing Guide)

## ۱. اجرای تست‌ها
تست‌ها بر روی پایگاه داده ایزوله در حافظه (In-Memory SQLite) اجرا می‌شوند:
npm test

## ۲. لایه‌های تست (Test Suites)
- tests/tier1/accounting.test.js: آزمون‌های سند دوبل، ترازنامه، سود و زیان، تراز آزمایشی
- tests/tier1/pos_returns.test.js: تخصیص FEFO، ایزولاسیون بیعانه، مرجوعی سالم/معیوب، ضد دابل‌ریترن، تعویض
- tests/tier1/procurement.test.js: فاکتور خرید، تسویه بدهی تأمین‌کننده، برگشت خرید، معین و سنی‌بندی
- tests/tier1/crm_wallet.test.js: واریز/برداشت کیف پول، حفاظت مانده نامنفی، تبدیل امتیاز وفاداری، مشتری ۳۶۰
