# راهنمای مهاجرت پایگاه داده و نسخه ارتقا (Migration Guide)

## ۱. اصول ایمنی پایگاه داده
1. پشتیبان‌گیری آنلاین قبل از تغییر: npm run backup
2. بازیابی در صورت بروز خطا: npm run restore

## ۲. اجرای مایگریشن‌ها
npm run migrate

## ۳. ایجاد مایگریشن جدید
فایل با پیشوند شماره افزایشی در db/migrations/ ایجاد کرده و npm run migrate را اجرا کنید.
